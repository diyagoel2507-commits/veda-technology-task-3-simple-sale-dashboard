# Simple Sales Performance Dashboard

## Project Overview

This project presents an interactive sales performance dashboard developed using Microsoft Power BI. The dashboard provides a clear overview of sales, profit, units sold, monthly trends, product categories, and regional performance.

## Objectives

- Analyze overall sales and profit performance
- Track monthly sales trends
- Compare sales across product categories
- Analyze regional sales performance
- Provide interactive filtering for better analysis
- Present key business metrics through an easy-to-understand dashboard

## Key Dashboard Features

- Total Sales
- Total Profit
- Units Sold
- Monthly Sales Trend
- Sales by Product Category
- Sales by Region
- Region Filter
- Month Filter
- Chronological monthly analysis

## Tools and Technologies

- Microsoft Power BI
- Microsoft Excel
- DAX
- Data Visualization
- Data Analysis

## Dataset

The dataset contains the following fields:

- Order Date
- Month
- Product
- Category
- Region
- Unit Price
- Quantity
- Sales
- Profit
